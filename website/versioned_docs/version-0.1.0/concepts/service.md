# Service

## Definition

A Component that is independently deployable.

**Avoid**: app, microservice, deployable

## Notes

Services form the primary nodes of the Macro Map. Their deployable nature is
detected from deployment artifacts (Dockerfiles, Helm charts, deployment
manifests).
