# Infrastructure

## Definition

A shared stateful datastore, message broker, or middleware (e.g. PostgreSQL,
Kafka, Valkey) used by Components.

**Avoid**: resource, backend

## Notes

Infrastructure nodes appear in the Macro Map alongside Components and are the
targets and sources of Contracts (topics, schemas, queues).
