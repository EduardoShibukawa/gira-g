# Contract

## Definition

A boundary specification representing an interface, endpoint, RPC method, or
message schema (e.g. gRPC service/method, HTTP route, Kafka topic definition).


## Notes

Contracts are how Components interact across process boundaries. Gira
extracts them from manifests and code, then joins them to their consumers
through change-impact analysis.
