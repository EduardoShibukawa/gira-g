## How we use it

Studied, never depended on. Human-surface + distribution reference, not extraction. Decided 2026-10-14 with owner: Docusaurus is **not** used inside the `gira` product (Go single binary, deterministic, LLM-free viewer). Optional future use is limited to the project's own docs website (`website/`, separate concern, never a Go runtime dependency).

## USE / COPY / NORTH STAR

- **USE:** nothing (JS/Webpack stack incompatible).
- **COPY:** serializable data-plane/render-plane split; sidebar as ordered ID list (explicit+autogenerated, multi-sidebar, pagination, breadcrumbs); `current vs latest` versioning (`versions.json`, banners, <10 active); faceted contextual search (→ component/version scoping); preset fan-out + prefer-wrap + Safe/Unsafe/Forbidden + markers-only upgrades.
- **NORTH STAR:** committed content + LLM-free viewer; deterministic changelogs from diffs; no Ask-AI (ADR 0001).
